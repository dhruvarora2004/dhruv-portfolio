## Overview

An academic project completed at Hansraj College, University of
Delhi, under Prof. Kapil Kumar (Department of Mathematics), applying
statistical distribution theory and regression analysis using
advanced Excel.

## Context

Coursework project for the Mathematics department, focused on applying
classroom statistics concepts to real data using Excel's built-in
statistical tooling rather than a programming language — a deliberate
scope, since the goal was demonstrating statistical understanding, not
building a software system.

## What Was Done

- Modeled and analyzed data using binomial, Poisson, and normal
  distributions
- Performed regression analysis using Excel's Data Analysis ToolPak
- Built Pivot Tables to summarize and cross-tabulate results
- Used advanced Excel functions throughout for data preparation and
  statistical calculation

## Tools

Advanced Excel (Data Analysis ToolPak, Pivot Tables, statistical
functions)

## Outcome

Completed as part of coursework, reinforcing the statistical
foundations (distribution theory, regression) that later informed
evaluation-design choices on independent projects like Retail
Analytics Copilot.
