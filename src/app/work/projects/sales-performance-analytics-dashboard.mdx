## Overview

An independently built retail sales analytics dashboard covering
200,000 records, using a star-schema data model for efficient
querying and Power BI for interactive reporting.

## Problem Statement

Raw transactional retail data isn't directly usable for business
decision-making — it needs to be cleaned, modeled, and shaped into a
schema that supports fast, flexible reporting across dimensions like
time, region, and product category.

## Dataset

A 200,000-record retail sales dataset with transactional-level detail
across products, regions, and time periods.

## Architecture

Data was modeled using a star schema — a central fact table of sales
transactions connected to dimension tables (product, region, date,
customer) — which is the standard approach for reporting performance
at this scale, since it avoids the slow joins that a fully normalized
schema would require in a BI tool.

## Tech Stack

Python (data cleaning and preparation), Excel (intermediate
transformation and validation), Power BI (data modeling with DAX,
dashboard design, and publishing)

## Methodology

Data was cleaned and validated in Python and Excel before being loaded
into Power BI, where the star schema was built and DAX measures were
used to calculate key business metrics (revenue trends, regional
performance, category breakdowns).

## Results

Delivered an interactive dashboard supporting drill-down analysis
across region, product category, and time period, with key metrics
surfaced through DAX-calculated measures.

## Tech Stack Details

Star-schema data modeling, DAX measures, interactive filtering and
drill-down, Power BI Service for report access.
